Privacy Policy

Zero tracking. Zero accounts. Zero telemetry. True private browsing by architectural design.

The Core Philosophy

"Zero logs. Zero user profiling. Pure private browsing."

Unlike corporate browsers that monetize your behavioral profile, NeoBrowser does not track, collect, transmit, or store any of your searches, visited domains, or keystrokes.

Zero Accounts & Zero Trackers

There are no user accounts, no login walls, no analytics trackers, no ad beacons, and no fingerprinting scripts embedded anywhere in the browser or backend.

Sandboxed fetch:// Resolution

All .neo domains are resolved directly from public, verified directory mappings and loaded into isolated guest webviews with security sandboxing.

Open Source Verification

Every line of code powering both the Electron browser client and the Python serverless backend is 100% open source on GitHub for public review and independent audit.

The lightweight, decentralized web browser and application runtime for .neo domains.
