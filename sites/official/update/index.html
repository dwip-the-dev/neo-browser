Changelog & Release History

Continuous evolution of the NeoBrowser decentralized engine, registry, and application runtime.

v2.2.0 Latest Release
2026 Updates
  • NeoSearch Engine Portal: Google-style homepage with live autocomplete, keyboard navigation (Ctrl+K, /), and direct Google Web fallback.
  • All 45 Sites Operational (100%): Resolved typing game directory pathing and created The Cube (3D interactive rotating WebGL/CSS experience).
  • 4-Site Random Discover Grid: Clean hero presentation showing 4 randomized featured sites on load with a 1-click "🎲 Roll 4 New" shuffle button.
  • Full Browser Chrome Controls: Integrated Back, Forward, Reload, and Home buttons interfacing directly with guest webviews.
  • Vercel Serverless Cloud Deployment: Zero-downtime global server handling all API endpoints, health checks, and asset delivery.
v2.0.0
Decentralization & Architecture
  • Dynamic server URL discovery with automatic fallback.
  • Added support for 30+ interactive HTML5/CSS/JS arcade games in registry.
  • Implemented unified fetch:// custom protocol resolver.
  • Hot reload developer mode powered by electronmon.
v1.0.0
Genesis Release
  • Initial release of NeoBrowser with basic registry mapping and local sandbox rendering.
  • Added troll pricing, privacy policies, and early official portals.
