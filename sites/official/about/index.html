About NeoBrowser

An open-source decentralized browser and runtime built by dwip-the-dev to give users complete autonomy, privacy, and instant access to .neo decentralized applications.

The Genesis & Philosophy

Traditional modern web browsers have become gargantuan operating systems in their own right — bloated with background telemetries, proprietary sync algorithms, search engine ad tracking, and walled gardens.

NeoBrowser was born from a simple thesis: what if a desktop browser was lightweight, sandboxed, and resolved web applications from a transparent decentralized registry without collecting a single byte of personal user data?

Under the Hood (Architecture)

NeoBrowser pairs a modular Electron frontend client with a high-performance Python serverless backend hosted on Vercel:

Electron & Chromium
Sandboxed Desktop Shell
Python 3.12 Flask
Serverless Registry Engine
Vercel Cloud
Global Edge Routing
fetch:// Protocol
Decentralized Mapping
