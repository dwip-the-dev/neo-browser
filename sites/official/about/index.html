NEOBROWSER

Decentralized Web Browser & Runtime Built on Electron and Cloud Serverless

Explore 45+ .neo domains and fetch:// URLs with a fast, responsive, and sandboxed browsing experience

What is NeoBrowser?

NeoBrowser is a privacy-first decentralized web browser built on Electron with a high-performance Python serverless backend on Vercel, designed to resolve .neo domains and fetch:// URLs directly from a global network registry.

It combines a modern desktop UI with an integrated search engine and sandboxed runtime, providing a fast, zero-tracking browsing experience with 45 pre-indexed decentralized applications and arcade games.

Features

🔗

Custom URL Scheme Support

Supports fetch:// URLs and .neo domains. Resolves them to local HTML files based on a registry JSON file.

🔍

Integrated Search

Search through registered sites with keywords. Live results appear in a dynamic sidebar/list. Clicking a result opens it directly in the embedded browser.

💻

Responsive UI

Sticky search bar always visible for repeated queries. Fullscreen content area for rendering web pages. Results and webview coexist without breaking layout.

🚀

Local Web Rendering

Uses PyWebView (Qt or GTK) to render local HTML files. Pages open instantly without external requests. Allows developers to simulate a lightweight browser experience.

🧩

Expandable Architecture

Registry-driven: easy to add new .neo sites. Modular Python API can be extended for more features.

How to Use NeoBrowser

Launch Browser

Opens with a blank page ready to search.

Search

Type a keyword or .neo domain in the top search bar. Press Enter or click Go.

View Results

Double-click a search result to open the page in the embedded browser. Search bar stays visible for repeated queries.

Add New Sites

Update registry.json with new domains and local HTML paths.

// Example registry.json entry
{
  "example.neo": {
    "name": "Example Site",
    "path": "/path/to/local/file.html"
  },
  "fetch://example": {
    "name": "Example Fetch Site",
    "path": "/path/to/another/file.html"
  }
}
